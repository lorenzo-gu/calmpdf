# CalmPDF terminology and naming style guide

## Brand
- Always use `CalmPDF` in user-facing prose.
- Use lowercase `calmpdf` only for domains, emails, handles, and repository identifiers.

## Primary tool labels
Use user language for top-level labels:
- `PDF to Word`
- `Word to PDF`
- `Edit PDF`
- `Rotate PDF`
- `Compress PDF`
- `Merge PDF`
- `Split PDF`

Technical file formats are supporting copy only, for example:
- `Exports .docx`
- `Supports .docx files`

## Navigation and hubs
- Tools hub label: `All PDF tools`
- Guides hub label: `PDF How-to Guides`

## UI copy casing
Use sentence-style UI copy:
- `How it works`
- `Related guides`
- `All PDF tools`

## Forbidden variants
Avoid these variants in primary labels and global nav/footer copy:
- `PDF to Word (DOCX)`
- `Word (DOCX) to PDF`
- `DOCX to PDF`
- `PDF to DOCX`
- `All PDF Tools`
- `How-to guides`
- `How-to Guides`
- `CalmPDF CalmPDF`
